# 风格方向：Chester 数字花园版

参考站点: https://chester.how/
方向: personal digital garden / editorial index / masonry portfolio

## 1. 为什么这个风格更适合个人网站

之前的方向偏“AI 出海增长系统落地页”，气势强，但更像服务商官网。
Chester 这种风格更像一个有审美、有积累、有项目、有生活气息的个人索引页。

它的优势：

- 更像真实个人，不像装出来的 agency。
- 可以同时放项目、文章、阅读、工具、生活兴趣。
- 视觉高级但不压迫，适合长期维护。
- 对 HR/老板来说，会觉得这个人有体系、有作品、有审美。
- 对潜在合作方来说，不会觉得你在硬卖服务。

## 2. 这个风格叫什么

可以叫：

- Digital Garden Portfolio
- Personal Index Page
- Editorial Masonry Portfolio
- Calm Personal Website
- Curated Personal Homepage

中文叫：

- 数字花园式个人网站
- 个人索引页
- 杂志式作品集
- 卡片瀑布流个人主页
- 内容策展型个人主页

## 3. 核心视觉特征

- 大量留白。
- 背景偏白 / 米白 / 很浅灰。
- 顶部导航极简。
- 首屏不是大营销标题，而是一段自然的自我介绍。
- 内容用卡片/拼贴/瀑布流展示。
- 项目、文章、阅读、兴趣混在一起，但靠标签区分。
- 图片真实、有质感，不全是科技抽象图。
- 字体克制，偏生活化和设计感。

## 4. 对 xyras.one 的新定位

网站不再像“我提供外贸数字化服务”的落地页，而是：

> 孙翔宇的个人数字花园，展示我正在构建的项目、出海系统、AI 工作流、阅读、写作和生活兴趣。

英文第一屏可以写：

```text
Hey, I’m Xyras.

I build export growth systems, AI workflows, and small software products.
Currently based in Zhongshan, working around B2B manufacturing, multilingual websites,
CRM workflows, and practical automation.
```

中文含义：

```text
我是孙翔宇，做出海增长系统、AI 工作流和一些小软件产品。
现在在中山，关注 B2B 制造业、多语言网站、CRM 流程和实用自动化。
```

## 5. 首页结构

### 5.1 Header

左侧:

```text
Xyras
```

右侧导航:

- Projects
- Writing
- Systems
- Reading
- About
- CV

外链:

- GitHub
- Email
- Resume

### 5.2 Intro

风格要像自然说话，不像广告文案。

```text
Hey, I’m Xyras.

Welcome to my digital garden. I like building useful systems at the intersection of
software, B2B export, AI workflows, and personal knowledge management.

These days I’m exploring how small manufacturing teams can use websites, product data,
CRM, and automation to build better overseas growth engines.
```

### 5.3 Card Grid

首页主体用卡片瀑布流，混合展示：

- Projects
- Systems
- Writing
- Notes
- Reading
- Tools
- Hobbies

卡片不必全等高。重点是像个人收藏墙，而不是企业服务列表。

## 7. 视觉规范

### 色彩

建议从深色 dashboard 改为浅色 editorial：

- Page background: `#F7F3EA`
- Card background: `#FFFDF7`
- Text primary: `#1F1F1D`
- Text secondary: `#6F6A60`
- Border: `#E7DFD1`
- Accent: `#4F7C64` 或 `#8A5A44`

### 字体

标题:

- `Fraunces`
- `Cormorant Garamond`
- `Playfair Display`
- `Georgia`

正文:

- `Inter`
- `Geist`
- `system-ui`

建议组合:

```text
标题: Fraunces / Georgia
正文: Inter / system-ui
```

### 卡片样式

- 圆角小，不要大圆角。
- 细边框。
- 轻阴影或无阴影。
- 卡片内图片比例可以不一致。
- 标签小而克制。
- hover 只做轻微上移或边框变深。

## 8. 和 Chester 的差异

不要完全照搬 Chester。

保留:

- 个人化 intro。
- digital garden 感。
- 内容卡片混排。
- 项目、写作、阅读、兴趣共同出现。

改掉:

- 不要太生活化，项目权重要更高。
- 不要让爱好压过职业定位。
- 不要用太多无业务价值的卡片。
- 不要只做“好看”，必须能支持求职和合作。

## 9. 首页信息优先级

优先级从高到低：

1. 你是谁。
2. 你正在构建什么方向。
3. 你做过的真实项目。
4. 你如何思考出海/AI/系统。
5. 你的写作和阅读。
6. 你的生活兴趣。

Hey, I’m Xyras.

Recently, I’ve been exploring how small manufacturing teams can use multilingual websites,

短版:

```text
Hey, I’m Xyras.

I build export growth systems, AI workflows, and small software products.
Currently based in Zhongshan, China.
```

## 11. 结论

最终不做“AI 外贸服务商官网”，改做：

> 一个浅色、克制、内容策展型的个人数字花园。

它的底层仍然服务求职和个人品牌，但表面上更自然、更可信，也更适合长期维护。
